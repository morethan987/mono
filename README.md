# 壹刻 - mono

> **智能日程规划引擎，让你专注当下。**

`mono` (壹刻) 是一个基于 Rust 开发的现代化任务调度工具。它不只是一个 Todo List，而是一个拥有"大脑"的调度引擎。通过 CLI 与后台 Daemon 协作，它能根据任务权重、优先级、截止日期以及**你的工作习惯**（在线机器学习），自动推荐你此时此刻最该处理的任务。

---

## ✨ 核心特性

- 🧠 **在线智能学习**：采用 FTRL (Follow The Regularized Leader) 与多臂老虎机 (Multi-Armed Bandit) 算法，学习你的完成率、反馈习惯和高效时段。
- ⚡ **CLI + Daemon 架构**：极轻量级的后台守护进程处理调度逻辑，CLI 提供极致流畅的交互体验。
- 🔔 **交互式通知**：深度集成 Linux DBus 通知系统。任务到期时弹出交互窗口，支持直接点击"完成"或"推迟"。
- 📅 **科学调度算法**：综合考虑任务优先级、截止日期衰减、任务类型偏好和能量状态。
- 📊 **学习统计**：通过 `mono stats` 查看你的工作效率趋势和各时段的胜任度。
- 💡 **智能时段推荐**：基于历史数据推荐最佳执行时段，帮助你在正确的时间做正确的事。
- 🗄️ **持久化存储**：基于 SQLite (sqlx) 实现，确保任务与模型数据安全可靠。

---

## 🚀 快速开始

### 1. 安装
确保已安装 Rust 环境 (1.75+)，然后克隆并编译：
```bash
git clone https://github.com/morethan/mono.git
cd mono
cargo build --release
```

### 2. 启动守护进程
`mono` 需要一个后台进程来运行调度引擎和发送通知：
```bash
# 后台启动
mono daemon start

# 或者在前台启动以查看实时日志
mono daemon start -f
```

### 3. 添加任务
```bash
# 添加一个紧急工作任务
mono add "撰写周报" -p high -t work -e 30 -d "2026-02-01 18:00"

# 添加一个日常学习任务
mono add "阅读 Rust 文档" -t study -e 45
```

### 4. 核心工作流
```bash
# 查看现在该做什么（附带智能时段推荐）
mono now

# 查看今日安排
mono today

# 标记完成（支持交互式反馈，帮助引擎学习）
mono complete <task_id>

# 跳过反馈快速完成
mono complete <task_id> -s

# 重新规划并查看评分排名
mono replan

# 查看学习统计
mono stats

# 查看详细统计（含时段成功率）
mono stats -v
```

> mono 不是一个全能的日程推荐与安排软件，而是一个更加智能的备忘录，尽可能方便地让你完成当天的工作，适配你的习惯让你更舒服地完成任务；因此mono最佳的使用方式应该是每天早上起床或者昨天晚上睡前，安排好自己的工作，然后从mono中抽取任务进行完成

## 🛠️ 技术架构

- **语言**: Rust (Edition 2024)
- **异步运行时**: Tokio
- **数据库**: SQLite (sqlx)
- **IPC**: Unix Domain Socket + JSON Codec
- **通知**: zbus (Linux DBus)
- **ML 引擎**: 自研 FTRL + Thompson Sampling 模块
- **UI 格式化**: tabled

---

## 📈 学习与进化

`mono` 会随着你的使用变得越来越懂你：
- **时段偏好**：如果你经常在上午推迟"学习"任务而在晚上完成，引擎会自动降低上午安排学习任务的权重。
- **难度感知**：如果你在完成某类任务后反馈"精疲力竭"，引擎会学习在低能量时段避开此类任务。
- **置信度系统**：采用 sqrt 缩放的混合模型，在冷启动阶段依赖全局规律，随着数据积累逐渐过渡到你的个性化模型。
- **模型持久化**：学习模型自动保存到数据库，重启后无需重新学习。
